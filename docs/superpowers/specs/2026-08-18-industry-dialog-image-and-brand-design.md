# 行业详情图片与品牌字标调整设计

- 日期：2026-08-18
- 基线：V3 前端预览
- 范围：行业详情弹窗、三个公开页面的左上角品牌区、相关自动化测试

## 1. 行业图片布局

八个行业继续使用现有八张场景图片，不重新生成或替换图片内容。

电脑端详情弹窗采用用户确认的 B 方案：顶部信息区左侧显示行业名称和场景说明，右侧显示约 30% 宽度的场景图片。图片使用约 16:10 的稳定比例，不贯穿弹窗全高。核心指标、计算方式、验收说明和 GIS 扩展内容位于下一行并占据完整宽度，避免文字被图片压缩成窄列。

较窄窗口下，顶部信息区改为纵向排列，文字在上、图片在下，正文继续使用完整宽度，不产生横向滚动。

## 2. 品牌区调整

首页、标准制定页和企业服务页左上角全部删除 `SE` 字样及其占位，只保留“智能系统与工程能力中心”和必要的能力域副标题。导航结构和页面链接不变。

## 3. 测试与发布

- 验证八个行业详情均显示各自对应图片，图片加载完成且自然宽度大于 0。
- 验证 GIS 扩展内容仍完整显示。
- 验证三个页面不存在可见的 `SE` 品牌字标。
- 验证 1366×768 和 1920×1080 下弹窗无横向溢出、文字不拥挤。
- 修正旧的线上图片测试，使其与恢复图片后的页面一致。
- 保持 `version-2-final` 标签不变，在 V3 基线上发布新检查版本。

## 4. 不做事项

本次不修改行业文字、指标口径、标准中心内容、企业服务流程和八张图片本身。
