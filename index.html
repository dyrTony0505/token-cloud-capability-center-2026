芯片类型计算特点典型工作负载国产适配与验证边界
CPU通用指令与复杂控制能力强，承担系统控制面、数据预处理，也可运行轻量模型。任务调度、数据处理、检索服务、轻量推理以及 GPU/NPU 主机侧协同。核对指令集、操作系统、编译器、框架、虚拟化能力和整机兼容清单。
GPU擅长高并行浮点与张量计算，软件生态和通用性较强，但训练、推理能力取决于型号与软件栈。大模型训练、微调、在线或批量推理、科学计算和图形计算。国产方案处于持续演进阶段；不能只按峰值算力判断，应实测算子覆盖、互联、显存和稳定性。
NPU面向神经网络计算优化，通常强调能效与专用算子；并非天然只适合推理。训练或推理、云边端协同、视觉与语言模型服务，能力以具体产品和框架为准。重点验证模型转换、算子支持、精度保持、工具链、互联和集群能力。
FPGA逻辑可重构，可按数据路径和时延目标定制，开发与维护门槛较高。特定算子、流式数据处理、低时延链路、协议卸载和行业专用加速。国内外均有方案，生态相对专用；需把开发工具、IP 核、时序、功耗和长期维护纳入验收。

  3. 03
    试点上线

  4. 04
    规模运营

    持续进行容量预测、版本治理、账单复核和 SLA 复盘；技术优化统一引用阶段二基线。

OPTIMIZATION LOOP技术优化五步循环：始终引用已验收基线
  1. 01基线观测

    从阶段二基线读取性能、质量、资源、能耗、成本和稳定性数据。

  2. 02定位瓶颈

    贯通资源、推理、接口、任务、计量、日志与告警，确认主导因素。

  3. 03单变量优化

    逐项验证量化、算子、批处理、KV Cache 和调度策略，控制变量。

  4. 04同口径复测

    沿用基线条件比较收益、质量损失、错误率和成本变化。

  5. 05安全容灾回归

行业场景

同一种 Token，不同的业务约束

以业务任务而非泛行业标签组织内容，覆盖八个具备明确评价口径的重点方向。

八个重点行业场景按统一框架对照：先定义任务，再固定数据、采集、统计与验收口径。

8 个场景
行业 / 场景计算指标与测量方法指标说明 / 验收判断详情
低空经济—低空巡检场景mAP、MOTA / IDF1、定位误差、告警时延、链路可用性连续采集飞行日志、感知标注和链路监控，按架次与风险场景统计 P50 / P95 / P99。重点验证实时告警、安全冗余、弱网与多传感器融合；按任务风险分别设阈值，并复核失败样本和安全降级。相对低优先级：离线大批量吞吐和极致单位成本。
具身智能—协同作业场景任务成功率、碰撞率、轨迹误差、端到端时延、恢复成功率按任务难度和环境扰动分层，记录传感器、规划器、控制器及恢复日志。动作安全和闭环稳定优先于峰值吞吐；验收同时约束成功率、碰撞率与恢复率，不能只看平均值。相对低优先级：脱离任务质量的峰值吞吐。
GIS / 测绘—遥感识别场景IoU、mAP、配准误差、拓扑错误率、P95 查询时延使用带真值标注的影像与矢量成果，按区域、地物类别、数据规模及并发分层统计。识别精度、坐标一致性和快速检索并重；非实时制图任务不强求毫秒级首 Token。相对低优先级：非实时成果生产中的极限首 Token 速度。
医疗行业—智慧医疗场景灵敏度、特异度、AUROC、F1、漏诊率、报告时延以脱敏病例和专家标注为真值，按病种、设备、机构与人群分层，保留医生复核记录。诊断精度、漏诊风险、追溯和医生复核优先；验收阈值由具体适应证与临床评价方案确定。相对低优先级：满足临床时限后的极限生成速度。
金融行业—风控场景AUC / KS、召回率、误报率、损失率、审计追溯时延从带结果标签的历史业务样本采集，按客群、产品、时间窗及风险等级监测漂移。风险可解释、稳定性和审计优先；阈值需同时满足误报成本、漏放损失和公平性约束。相对低优先级：单次输出长度和生成文风。
工业制造—质量检测场景良率、缺陷检出率、漏检率、节拍、OEE、停机时长联接质检、设备与停机记录，按产线、产品、缺陷类别和班次连续统计。确定性、工艺安全和连续运行优先；漏检与误检必须成对报告，并通过节拍和故障恢复验证。相对低优先级：通用对话体验。
能源电力—设备巡检场景负荷预测 MAE、故障召回率、告警时延、可用性、约束满足率采集调度、设备、气象和告警闭环数据，按区域、季节、时间粒度及极端天气分层。安全稳定、预测可靠与告警闭环优先；除平均误差外必须评估极端场景和漏报。相对低优先级：界面生成速度。
交通物流—路径调度场景ETA MAE / RMSE、履约率、调度耗时、异常识别召回联接订单、轨迹、路况和异常工单，按路线、时段、天气和订单类型分层统计。预测准确、调度效率、峰值稳定和成本优先；验收需覆盖高峰、异常和跨区域泛化。相对低优先级：复杂生成效果。
